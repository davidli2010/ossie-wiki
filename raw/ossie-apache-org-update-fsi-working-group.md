# The FSI Semantic Working Group Is Live

金融服务中，AI agents 正在产生真实业务成果。跑得最快的公司有一个共同点：他们先解决了语义层。

## 背景论点

- 金融服务业正在把 agentic AI 从实验推进到真实业务流程：把机构流程从数天压缩到数分钟，提升决策质量与速度。
- 走在前面的公司不是坐等更好的模型或算力，而是先构建一致、可信的语义层，在 agent 接触数据之前赋予其意义。
- 未解决的公司面临常见障碍：难以建立给数据一致业务含义与上下文的语义层；agent 无法可靠理解业务，输出质量与决策面临风险。
- 这不仅是技术问题，也是协作问题，没有任何单一机构能独自解决。

## 为什么需要集体响应

- 在金融服务业，每个机构都独立建模大量相同的核心概念：trades、positions、instruments、claims、accounts、entities、transactions、exposures。
- 但跨机构没有共享词汇来锚定这些概念。
- 结构性标准给了行业线格式（wire formats），帮助系统交换数据，但本身不能给出"数据意味着什么"的共享语言。
- 成本可度量：低效集成、不一致的 AI 输出、重复建模工作、远超技术本身需要的 time-to-value。当 AI agents 自主、大规模、跨机构边界运行时，未解决的语义错位从数据质量问题升级为业务风险。

## 工作组

2026-06-03（周三），金融服务语义工作组在 OSI 旗下举行首次正式会议。这是一个行业倡议——由从业者为从业者召集。

当前参与者包括 **Northern Trust、DTCC、Cotality、LSEG、Verisk、BlackRock、S&P Global、AIG、Equilar、TIAA** 等。覆盖银行、保险、资管、财富管理、市场基础设施、数据提供商。

## 达成的共识

首次会议不是交付成果，而是对问题、原则与工作形态达成一致。

工作组批准了正式问题陈述：

> "结构性标准给了我们线格式；它没有给我们共享语言。在金融服务中，数据提供商与机构独立建模相同核心概念——没有共享词汇来锚定它们。"

决定成立三项倡议：

### Architecture
提出工作组起步架构：初始功能与对象集合，用 Mermaid 表示并附 Markdown 描述假设、设计选择与未决问题。架构提案将通过 OSI GitHub 共享。

### Measurement of Commercial Impact
采纳与影响必须可度量。提议测量 OSI 标准采纳的具体方法，并随时间展示商业影响。

### Structure
金融服务不是一个整体，由多个子行业构成。该倡议将建议如何跨子行业与功能领域组织金融服务语义。

完整会议纪要文档即将发布。

## 接下来

工作组进入各倡议的并行工作流。每个倡议将提出建议供未来工作组会议评审讨论。
