# Open Semantic Interchange (OSI) Updates: Specification Now Live, New Working Group Members and More

## 摘要
现代企业的关键障碍不是缺数据，而是**缺乏共享意义**。业务逻辑与定义（churn rate、net margin）长期锁在专有孤岛中，团队被迫反复重建相同语义上下文。

本文宣布 OSI 从愿景迈向基础性行业标准的多项里程碑。

## OSI 规范上线
- **OSI 规范首个版本现已可用**，位于 Apache 2.0 许可的 Git 仓库（github.com/open-semantic-interchange/OSI）。
- 规范定义厂商中立、可扩展的语义层构造表示模型（data sets、metrics、dimensions、relationships、contexts），可跨工具、平台与 agentic 应用一致解释。
- 定位为起点而非终点：社区反馈、讨论与贡献将塑造其演进。

## 生态扩张
新增工作组成员：**AtScale, Coalesce, Collate, Credible, Databricks, JetBrains, Lightdash, Qlik**（8 家）。

既有成员：Alation, Atlan, BlackRock, Blue Yonder, Collibra, Cube, DataHub, dbt Labs, Domo, Elementum AI, Firebolt, Hex, Honeydew, Informatica, Instacart, Mistral AI, Omni, Preset, RelationalAI, Salesforce, Select Star, Sigma, Starburst Data, Strategy, ThoughtSpot。

## open-semantic-interchange.org 上线
项目网站开放：提供规范访问、工作组成员目录与社区更新。

## 展望：开放、基金会主导的未来
- OSI 自始设计为 community-first 项目。
- 随倡议成熟，将过渡到中立的、基金会主导的治理模式。

> 历史意义：文中所述"过渡到基金会主导治理"于 2026-07-10 落地（进入 Apache 孵化器、更名 Apache Ossie）。参见 [Apache Ossie 实体页](/entities/apache-ossie.md)。
