# Apache Ossie 社区

Apache Ossie 由个人组成的社区构建。欢迎所有人参与——无论贡献规范、构建转换器还是仅仅跟随。

## 参与渠道

- **View Repository**：浏览规范、提 PR、贡献代码（github.com/apache/ossie）
- **Start a Discussion**：分享想法、提议特性、提问（GitHub Discussions）
- **Join Slack**：与贡献者直接交流（apache-ossie Slack）
- **Subscribe to dev@**：主开发与社区讨论列表（dev-subscribe@ossie.apache.org）
- **Subscribe to commits@**：commits 与 PR 的自动通知
- **Subscribe to issues@**：GitHub issues 自动通知
- **Google Calendar**：订阅社区会议与活动

## 工作组

本倡议按专注小组组织，各组负责规范的特定领域：

- **Advanced Metrics & Expression Language**：复杂指标计算与可移植表达式语法
- **Composability**：使语义模型能够相互引用与扩展
- **Catalog Integration**：把 Apache Ossie 模型与数据 catalog 及治理平台桥接
- **Ontology Representation**：将 Apache Ossie 概念映射到正式本体标准
- **Model Converters & Developer Tools**：导入、导出与验证 Apache Ossie 模型的工具
