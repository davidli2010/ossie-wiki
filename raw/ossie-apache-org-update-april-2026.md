# Open Semantic Interchange: Community Update and What's Next

OSI 倡议作为开放、社区驱动的努力持续演进，目标是定义跨数据与 AI 系统的语义互操作共享标准。

## 规范已上线并活跃演进

- OSI 规范现已公开，开发在开放中进行。
- 仓库（github.com/apache/ossie）成为讨论与迭代的活跃枢纽。
- GitHub Discussions 上社区参与的议题：如何可移植地表示指标与派生逻辑；semantic model composability 的权衡；OSI 与现有 catalog/metadata 系统的对齐；表示 ontologies 与关系的方法；开发者体验与采用工具。

## 工作组成形

| 工作组 | 关注领域 |
| --- | --- |
| Advanced Metrics & Expression Language | 复杂计算与派生逻辑的可移植表示 |
| Composability | 语义模型如何在工具间组合、扩展与重用 |
| Catalog Integration | 与现有数据 catalog 与元数据系统对齐 |
| Ontology Representation | 建模关系、层级与领域知识 |
| Model Converters & Developer Tools | OSI 与厂商特定格式之间转换的工具 |

## 公开路线图

引入公开路线图（ROADMAP.md），对即将到来的优先事项与关注领域提供透明性。路线图将随社区输入演进。

## 生态参与增长

新工作组参与者（14 个）：Anomalo、Bigeye、CARTO、Cloudera、Coginiti、Count、Dataiku、Denodo、Dremio、GoodData、Metabase、Oracle、Sundial、Zeta Global。

这种多样性确保标准保持广泛适用，不被任何单一工具或厂商塑造。

## 如何参与

- GitHub（主枢纽）：评审 spec、开 issues、提 PR
- GitHub Discussions
- Ecosystem Contributions：构建或贡献进出 OSI 的转换器
- 所有贡献由工作组评审，项目遵循开放源码模型

即使不加入正式工作组也可以：fork 仓库提变更、参与架构与用例讨论、关注仓库保持最新。
